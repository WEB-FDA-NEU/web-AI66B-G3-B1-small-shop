# Team 3 - YUMS - small shop managing system - Milestone 2 submission

## What has been implemented.
1. Login; Register; Home screen; 404 page.
2. Create new Order; see all orders; see a specific order details.
3. Customer pages, create new customer, see customer's detail, edit customer's information.
4. See all employees information, add new employee, edit employee's information
5. See general sales with summaries, predict demand screens. 
6. Suitable filters to all the screens or features

**NOTE:** Every features can be used right away, yet the data structures are just sample in .js files. Anything can be changed in the future. This submission is a prototype for the product demo, not the final result.

## How to open/run the project.
1. Open file **html/index.html**. 
2. Insert anything or nothing in the input boxes, press 'login' you will be at the home directory.
3. Navigate to anywhere you want from the sidebar.
4. To comeback the home page, press on the logo 'YUMS'.
5. To see 404 page, paste to URL: http://127.0.0.1:5500/code/frontend/html/error_screen.html
